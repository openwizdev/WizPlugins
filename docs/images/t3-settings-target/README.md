# T3 Settings layout targets

Synthetic dark-mode mockups for the WizBar Settings tab in T3.

| Viewport | Target |
| --- | --- |
| 390 CSS px | [Phone with the reviewer picker closed](settings-phone-390.png) |
| 1440 CSS px | [Desktop with the reviewer picker open](settings-desktop-1440.png) |

Compare the selected Settings icon in the rail, the Ask Wiz box at the top, and the order of Who does what, Where agents run, and Usage. At 390 px, check that each role has a readable selected value and that all rows, controls, and meters fit within the page width. In the desktop picker, check the meters beside eligible accounts, the reason the builder's model family is disabled, and the note explaining why reserved accounts are hidden.

[OpenWiz #3980](https://github.com/openwizdev/OpenWiz/issues/3980) will produce the browser screenshots at both widths in `docs/evidence/t3-settings/` in WizPlugins.
