# Needs you design brief

The [feed spec](https://github.com/openwizdev/OpenWiz/issues/3408) and the rail at [prototype revision 2e16faa](https://github.com/openwizdev/WizPlugins/blob/2e16faa0462739f51ed12e3ff3da179304b65a22/t3/board/rail.ts) govern this pair. The task is to find an outstanding approval or merge quickly. The required shell is dark, with the board's vertical rail and its Needs you default. Use the prototype's neutral surfaces, compact system sans, fine divider and small amber attention marks. The prototype's repeated left edges and restrained selection fill guide alignment. Use the public prototype for the rail and surface only.

Use #161616 canvas, #222222 raised cards, #ededed primary text, #b7b7b7 secondary text and #fc8c45 attention. Use a 19–22 px semibold heading, 14–15 px card titles and 12–13 px labels. Align labels and cards to one edge. Give cards 8 px corners, 12–16 px inner padding and 8 px gaps. On desktop place the labelled 128 px rail beside a roughly 760 px wide single column with quiet space to its right. On phone use the prototype's 45 px icon rail and a single column with a 12–16 px gutter. Use a quiet filled selection for Needs you at both widths. The amber rail mark is a dot on the phone and a numeral on desktop.

## Synthetic content

| Kind | Text | Owner action |
| --- | --- | --- |
| Spec approval | Approve the export plan | Open its record |
| Ready to merge | Merge the report fix | Open its record |
| Scroll-only note | Export checks still running | None |
| Unavailable source | Usage unavailable · Source file is stale | None |

There are two open cards needing the owner. Both precede the scroll-only note. The unavailable source has a reason and contributes no count. Empty would say there are no items when the feed is available. A true zero needs no rail attention mark. With one card the section stays compact. A long record title wraps inside its card. Missing data remains unavailable in words.
