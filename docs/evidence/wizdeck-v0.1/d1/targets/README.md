# D1 (#73) target pictures

Design targets for the WizDeck Home panel, made before any visible code. They are generated pictures, not screenshots; they prove nothing about the real page.

- `desktop-1440.png`: 1440 x 900, the app window with WizDeck in the right panel.
- `phone-390.png`: 390 x 844, the same panel as the phone's right panel.
- `prompt.txt`: the exact prompts and route (built-in image generation through a Codex helper, no API key).

All content is invented. The design follows the confirmed Ledger style in the ticket's words: dark surface, compact rows, thin separators, lime only on progress, a big-number Running/Health row, no credits. D1 has no send controls, so Needs you rows show options as text with an Open link.

Known target defects, to fix in the build rather than copy: the phone's Open buttons are under 44 px tall (the build uses 44 px tap targets); the desktop panel is slightly wider than a real right panel; the invented version headings ("2/3 specs") do not match their rows (the build shows verified ticket progress).
